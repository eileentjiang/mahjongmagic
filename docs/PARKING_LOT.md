# Mahjong Magic: Parking Lot

Ideas that are **out of scope for the MVP** (see [`PRD.md`](./PRD.md)), kept here so they aren't lost. Each item notes where it came from and a rough horizon:

- **Next:** a strong candidate for the first iteration after the MVP
- **Later:** valuable, but needs the MVP to prove itself first
- **Someday:** big bets or niche ideas

Prioritize these in the feature-prioritization phase (e.g. with RICE or MoSCoW).
